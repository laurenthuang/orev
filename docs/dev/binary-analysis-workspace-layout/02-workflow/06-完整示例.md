> **`00_inbox` 保留原始文件名**，不做统一改名。原因是 MECE 之外的三条：Ghidra 的 Program 名与 `FSRL` 取自文件名；多文件输入不需要额外结构；文件名本身可能是取证内容。代价由 `$TARGET_INPUT` 变量与 `input_file` 字段承担（[§5.2](../01-layout/04-阶段产物清单.md#52-00_inbox-两个元数据文件的职责边界)）。

> **示例树的省略规则**：用 `{stage.yaml,out/,log/}` 折叠的阶段目录，其槽位与 [§4.1](../01-layout/03-阶段目录契约.md#41-槽位结构任何阶段目录内只有这三样) 契约完全一致，产物名写在同行注释中。用 `{00_inbox, 20_static, …}` 折叠的目录，连槽位一并省略。本示例树是**结构示意**，不是产物穷举。
