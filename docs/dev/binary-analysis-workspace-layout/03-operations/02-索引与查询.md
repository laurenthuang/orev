# 9. 索引与查询

## 9.1 `state/index.jsonl`

样例见 [`schemas/index.jsonl`](../schemas/index.jsonl)。每行一个 JSON 对象。

`path` 字段**相对案件根目录**。以 `store/` 或 `tools/` 开头的路径是逻辑命名空间，物理位置由 `store_root` 与 `tools_root` 决定（[§2.1](../01-layout/01-顶层布局.md#21-冷区-store-与工具资产区-tools)）。阶段进入 `status: ok` 时，脚本从 `stage.yaml` 的 outputs 追加写入索引。**只有 ok 状态的产物才会进入索引**。这条规则保证索引中查到的产物一定可信。

## 9.2 高频查询

四条常用查询见 [`scripts/query-index.sh`](../scripts/query-index.sh)：体积 Top 20、全文检索、待补证据的弱结论、按保留级别统计。

> 产物数量过万、或需要依赖追溯时，再引入 SQLite 或 DuckDB。`index.jsonl` 可直接 `COPY` 进去，无需改动格式。
