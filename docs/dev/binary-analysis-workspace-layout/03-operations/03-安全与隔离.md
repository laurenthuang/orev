# 13. 安全与隔离（恶意样本）

| 项 | 约定 |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 目录权限 | `sample/` 整体 `chmod 700`，与其他类型物理隔离 |
| 静态纪律 | 默认**不执行**目标；容器 `--network=none`，目标只读挂载 |
| 动态隔离 | `40_dynamic/` 仅在专用虚拟机 / 容器中产出，回传前先扫毒 |
| 脱敏 | `provenance.json` 中的授权信息、内部路径、同事姓名在交付前脱敏 |
| 留存期限 | `orev.toml` 中写明 `sample.retention_days`，到期清理 required 之外产物 |
| 完整性 | 样本本身的哈希每次分析前后校验，不一致视为安全事件（[§8.3](../03-operations/01-保留分级与清理.md#83-完整性校验)） |
| 法律边界 | 只分析自己拥有或已获授权检查的软件；商业工具（IDA / Hopper / JEB）需合法授权 |
| 工具自身安全 | **分析工具本身也是攻击面**：Ghidra / IDA 需要解析不可信文件，其 parser 漏洞可被利用（例如 Ghidra < 12.1.4 的 CVE-2026-96273 拒绝服务漏洞）。保持工具更新；陌生样本在隔离虚拟机中打开；只从官方 GitHub Releases 下载工具 |
| 密钥 | `signing_material` 只记路径与指纹，**绝不记录密钥、口令、p12 内容** |
